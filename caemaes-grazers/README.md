# CaeMae's Grazers

Static site for a graze board business. Plain HTML and CSS, no build step.

## Publish on GitHub Pages
1. Create a repo (for example `caemaes-grazers`) and upload everything in this folder.
2. In the repo, open Settings > Pages.
3. Set Source to "Deploy from a branch", pick `main` and `/ (root)`, then Save.
4. The site goes live at `https://<your-username>.github.io/<repo-name>/` within a couple of minutes.

## Things to change before sharing
- `index.html`, bottom script: set `CONTACT_EMAIL` to the real address.
- Add a service area and a social link in the footer once they exist.
- Add real pricing if you want it public. The page currently says quotes are built to order.
- Swap the sample illustrations for photos: drop JPGs into `images/` and change the `src` on each `<img>`.

## Images
The four sample boards in `images/` are illustrations generated by `make_boards.py`.
Run `python3 make_boards.py` to regenerate them after editing the script.
